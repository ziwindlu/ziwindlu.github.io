what#

route是任何网络中选取路径的程序

why#

解决数据从源节点到目标节点的有效传输问题

how#

以linux中ip命令为例 查看路由

ip route show

添加路由

# 添加默认路由
ip route add default via 192.168.1.1 dev eth0
# 添加静态路由
ip route add 10.0.0.0/8 via 10.0.0.1 dev tun0

删除路由

ip route del 10.0.0.0/8

修改路由

ip route replace 10.0.0.0/8 via 10.0.0.2 dev tun0
