概念#

包#

go从main包开始运行 声明包

package main

导入包 通常你不需要自己导入包，写代码时编辑器会帮你导入

import "fmt"
import (
"fmt"
"math"
)

导出名 导入一个包时只能使用其中已导出的导出名 当一个导出名以大写字母开头，那么这个导出名就是已导出的

语法#

方法#

定义方法#

必须定义入参类型和返回类型。 长得和py中的类似，方法要用开头小写的驼峰来命名

func myFn(add1 int, add2 int) int {
return add2 + add1
}

便捷写法#

如果参数的类型相同，并且挨在一起，那么可以这样写

func myFn1(add1, add2 int) int {
return add2 + add1
}

多个返回值 声明多个返回值使用(type1, type2)，接收多个返回值要使用:=

func sw(s1, s2 string) (string, string) {
return s2, s1
}
func main() {
a, b := sw("hello", "world")
t, _ := sw("hello", "world")
fmt.Print(t)
fmt.Println(a, b)
}

如果你只想接收一个，也必须使用:=，不想保存的参数使用_接收 更快捷的返回 使用变量名进行返回

func split(sum int) (x, y int) {
x = sum * 4 / 9
y = sum - x
return
}

变量#

无论使用var xx type显式的表示还是自动推导，一个变量是必须有类型的。

定义#

使用var来定义变量

var abc = "abc"
fmt.Println(abc)

如果你在方法内定义了变量，那么必须要使用它

批量初始化#

var a, b, c = 'A', 'B', 'c'
fmt.Println(a, b, c)

带类型的变量#

var a string
a = "string"
fmt.Println(a)

简短的声明#

使用:=做类型推导

a := "string"

常量#

使用const修饰

const var1 = 123
const (
var2 = 345
var3 = "345"
)

i = int(13.0)

go不会自动做类型转换，需要用户手动进行类型转换

循环#

for基本语法#

没有()的c的for

for i := 0; i < 10; i++ {
fmt.Println(i)
}

for的其他特性#

可选的初始化语句和后置语句

i := 2
for ;i < 10; {
i++
fmt.Println(i)
}

go中没有++i，也不能直接将i++作为值使用

while#

for可以不使用前置和后置语句，while在go中就是for

无限循环#

for {
fmt.Println("根本停不下来")
}

条件#

if基本语法#

没有()的c的if

if  1 == 1 {
fmt.Println("b")
}

if的其他特性#

初始化语句，这个初始化语句初始化的变量仅会在当前if内有效

if  b := 12;1 == 1 {
fmt.Println(b)
}

switch基本语法#

没有()的c的switch。当前case下有语句时，go自动帮你做break，switch的值可以是字符串或表达式。同样，switch也支持初始化语句，作用域也是当前switch。

color := "green"
switch rgb := 0x000000; color {
case "green":
fmt.Printf("0x%.6x\n", rgb^0x00FF00)
case "red":
fmt.Printf("0x%.6x\n", rgb^0xFF0000)
case "blue":
fmt.Printf("0x%.6x\n", rgb^0x0000FF)
default:
fmt.Println(rgb)
}

优雅的if-else-if-else#

使用无条件的switch替换

t := time.Now()
switch {
case t.Hour() < 12:
fmt.Println("Good morning!")
case t.Hour() < 17:
fmt.Println("Good afternoon.")
default:
fmt.Println("Good evening.")
}
