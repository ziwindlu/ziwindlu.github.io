特殊的变量#

坏境变量(均为大写) PATH可执行程序的路径 PWD当前所在的目录 SHELL当前使用的shell 常见变量 $0为该脚本本身的名字 $#：表示传入参数的个数。 $@：表示所有传入的参数（以独立形式显示，每个参数都保留为单独的字符串） $*：表示所有传入的参数（以一个字符串形式显示，所有参数被合并）

变量定义以及使用 限定符local当前作用域 export作为环境变量 name=value定义 $name使用

数据类型#

shell中的数据类型有整数、字符串、数组、关联数组(bash4.0及以后的特性) '和"的区别 '字符原始数据，"可以解析其中的变量值 数组使用

fruits=("apple" "banana" "cherry")
echo "First fruit: ${fruits[0]}"
# tostring
echo "All fruit: ${fruits[*]}"
# 列出所有内容
echo "All fruit: ${fruits[@]}"
# *和@两者的去区别可以参考常见变量
# 获取长度
length=${#fruits[@]}
echo $length
# 遍历
for fruit in "${fruits[@]}"; do
echo "Fruit: $fruit"
done
# 添加元素
fruits+=("date")
# 修改元素
fruits[1]="blueberry"
# 删除元素
unset fruits[1]
# 合并两个数组
more_fruits=("kiwi" "melon")
combined=("${fruits[@]}" "${more_fruits[@]}")
echo "Combined fruits: ${combined[@]}"
