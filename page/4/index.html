记录一次大量数据查询的优雅解决方案

引子 最近有了一个从大量json数据中做查询的一个需求，期间设想了多个方案，最后通过数据库查询这种还算优雅的方式解决了，记录一下。 写在前面 本篇通过具体案例来进行演示，其中数据源是大量的json，且为一个相同对象的数组，目的是从这些json中做查询、筛选。当然这并不是一成不变的，数据可以是任意格式，查询也可能千奇百怪，俺希望读者也能根据俺的思路举一反三，找到优雅的解决方案。 注意：对数据操作不当可能会导致损坏，这里仅作思路参考。 俺的心路历程 刚开始得知这个需求时，最初的json很大，打开非常耗时，并且在纯文本中对json做人肉解析实在有些难了，俺的解决方案是给他整成excel之类的格式，直接用图形化筛选就好了。 json转excel 最开始俺想复杂了，俺寻思先转成csv再转成excel(个人看法：在某种程度上这csv不就是excel嘛，所以这多转了一道)。 后来经过一顿摸索，直接整了个py脚本，json转excel。这个脚本会放到后面。 对于大量的数据来说，使用excel的筛选就有点捉襟见肘了。 json转csv,csv导入数据库 上一步中间转了一道csv。突发奇想为什么不能把这个csv扔到数据库里面呢，直接用数据库查询岂不是更爽。 经过一番摸索，发现可行。 不过有一些值得注意的点： 数据的预处理 数据库的选择 数据类型 俺摸索了一番发现可行后，就草草了事结束了。实际上对于不同的数据、不同的查询方式需要进行分类讨论，这就是上面值得注意的点的由来。 数据的预处理：在从json转换成csv时数据丢失、字段对不上等问题。 数据库的选择：你的数据存在这种数据库中是否合理，对你的查询方式是不是有影响，还有是否符合你自己的查询习惯。 数据类型：数据类型会影响到数据的预处理、数据库的选择，以及查询。 俺不是一个优秀的开发者，描述可能不清晰，还请大佬谅解。 基于例子的完整演示 大体步骤 将json中对象的字段提取出来->根据字段去创建mysql数据库->将json转换为csv格式并为csv添加一个头->将csv导入到数据库中->从数据库中查询数据 环境准备 我们需要用到的内容有:mysql数据库、dbeaver(数据库连接工具)、jq(处理json的工具) 以上提到的工具win、mac、linux都有，这里仅演示linux与mac mysql建议使用docker安装 # 创建数据目录 cd ~ mkdir -p docker/mysql/data mkdir -p docker/mysql/conf.d cd docker # 运行容器并挂载 docker run -d \ --name mysql-server \ -e MYSQL_ROOT_PASSWORD=123456 \ -v `pwd`/mysql/data:/var/lib/mysql \ -v `pwd`/mysql/conf.d:/etc/mysql/conf.d \ -p 3306:3306 \ mysql:8.3 dbeaver请使用社区版Download | DBeaver Community arch: sudo pacman -S dbeaver mac: brew install --cask dbeaver-community 或安装包安装 jq GitHub -
